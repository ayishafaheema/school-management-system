# School Management System

A Django-based School Management System with PostgreSQL.

## Features

- User Authentication
- Admin Dashboard
- Teacher Dashboard
- Student Dashboard
- Student Management
- Teacher Management
- PostgreSQL Database
- Login & Logout
- Profile Management
- Attendance Overview
- Academic Dashboard
- FullCalendar Integration

## Tech Stack

- Python
- Django
- PostgreSQL
- HTML
- CSS
- Bootstrap
- JavaScript

## Installation

```bash
git clone <repository-url>
cd school-management-system
pip install -r requirements.txt
